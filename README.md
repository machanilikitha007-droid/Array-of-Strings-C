# Array of Strings in C

**Author:** M.Likitha

## Description

This program demonstrates how to create and use an array of strings
in C. It stores five names and displays them using loops.

## File

array_of_strings.c

## Concepts Used

- Array of strings
- Two-dimensional character array
- String input
- `for` loop
- Array indexing

## How to Run

gcc array_of_strings.c -o array_of_strings
./array_of_strings

Name 2: Anu
